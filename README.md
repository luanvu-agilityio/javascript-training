# Javascript Practice

## Overview

Welcome to my first Javascript personal project. In this topic, I will make an admin dashboard which helps user to create and manage the invoices. You can find the all the links needed at the end of this file. The objectives of this project is to apply the Javascript knowlegde to handle the CRUD operations by managing the add/edit/delete features. Sorting and searching features are also included to improve the user experience.

## Step by step to run this app in your local
Command                                                                           | Action
----------------------------------------------------------------------------------|---------------------------------------------
git clone https://gitlab.asoft-python.com/luan.vu/javascript-training.git         | Download the source code                    
cd javascript-training                                                            | Move to folder
git checkout feat/practice                                                        | Checkout to branch feat/practice           
cd javascript-practice                                                            | Move to folder                             
npm install                                                                       | Install dependencies      
cd src                                                                            | Move to src folder
npm install -g json-server                                                        | Install JSON server
npm json-server                                                                   | Run JSON server
Ctrl + Shift + `                                                                  | Open new terminal
cd javascript-training/javascript-practice                                        | Move to folder
npm start                                                                         | Run the parcel bundler



Note:   
Database is running locally at http://localhost:3000 <br/>
Open the browser at: http://localhost:1234 <br/>
Alternatively, see deployment at: https://javascript-training-luanvu.vercel.app/
